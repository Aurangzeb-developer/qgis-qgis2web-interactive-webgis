# 🌍 Interactive WebGIS Map from QGIS using QGIS2Web

> Create and publish an interactive WebGIS map directly from QGIS — without building a web application from scratch.

![WebGIS Preview](screenshots/webgis-preview.png)

## 📌 Project Overview

This project demonstrates how to transform a GIS project created in **QGIS** into an interactive web-based GIS application using the **QGIS2Web** plugin.

The workflow takes GIS layers managed and styled in QGIS and exports them into a browser-based WebGIS application that can be opened locally and further customized using HTML, CSS, and JavaScript.

The project is designed as a practical workflow for GIS professionals who want to move from desktop GIS to interactive WebGIS without developing the entire application from scratch.

---

## 🎯 Project Objective

The objective of this project is to demonstrate a complete workflow for:

- Managing GIS layers in QGIS
- Styling and organizing spatial data
- Preparing a GIS project for web publishing
- Installing and using the QGIS2Web plugin
- Exporting QGIS layers to an interactive WebGIS
- Opening and testing the generated web application
- Customizing the exported HTML/CSS/JavaScript
- Creating a browser-based interactive GIS map
